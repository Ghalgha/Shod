# Трекер аудита проекта

## Правила аудита

1. Проверять **все файлы репозитория строго сверху вниз, в порядке Git-дерева**, по одному файлу за раз. Не перескакивать между файлами и не выбирать только крупные или подозрительные.
2. Перед проверкой каждого файла читать его полностью. Большие файлы изучать последовательно, без пропуска частей.
3. Проверять максимально тщательно и со всех применимых сторон:
   - правильность логики, условий и граничных случаев;
   - ошибки, исключительные ситуации и обработку отказов;
   - безопасность, проверку входных данных и границы доверия;
   - зависимости, вызовы, контракты и взаимодействие с остальным проектом;
   - жизненный цикл ресурсов, память, потоки и конкурентность;
   - производительность и возможные узкие места;
   - тесты, покрытие и отсутствие важных сценариев;
   - архитектуру, дублирование, мёртвый код и соответствие назначения файла;
   - конфигурацию, сборку, документацию и фактическое использование.
4. Не делать выводов по одному фрагменту: учитывать контекст проекта и при необходимости просматривать связанные файлы. При этом текущий файл остаётся единственным файлом, который отмечается как проверенный за один шаг.
5. Разделять подтверждённые ошибки, потенциальные риски и рекомендации. Для каждой проблемы указывать файл, точное место, суть, доказательства и последствия. Не записывать предположения как установленные ошибки.
6. Учитывать файлы любого типа, включая конфигурации, скрипты, документацию, ресурсы и сторонние файлы. Если содержимое нельзя полноценно проверить, прямо указать ограничение.
7. **Не изменять код и другие файлы проекта без прямого разрешения.** Не исправлять проблемы самостоятельно. TLS/HTTPS не менять.
8. После проверки одного файла обновить счётчик, имя последнего изученного файла и список найденных проблем, затем остановиться на этом файле до следующего шага пользователя.

## Найденные проблемы

### Подтверждённые проблемы

- `LICENSE` и `rust-server/Cargo.toml` (`[package].license`) — лицензия проекта объявлена проприетарной, но Rust-пакет указывает `Unlicense`. Это противоречивые юридические условия и некорректные метаданные пакета; требуется согласовать объявление Cargo с фактической лицензией. Файлы не изменялись.
