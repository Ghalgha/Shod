# Версионирование

Единая версия исходного проекта — `0.1.0`.

- Android-приложение: `versionName = "0.1.0"`, `versionCode = 1`.
- Rust-пакеты `shod-client` и `shod`: `0.1.0`.
- Debug- и Release-варианты используют одну и ту же базовую версию приложения; отдельный суффикс версии для Debug не добавляется.

## Происхождение встроенных бинарников

Встроенные бинарники в текущем репозитории были собраны ранее и сохраняют исходные версии: native client — `2.5.0`, server core — `2.5.3`. Эти значения в `artifactVersion` — сведения о происхождении конкретных файлов, а не версии проекта Shod.

Поля `repositoryPackageVersion` фиксируют версию пакета в текущих исходниках (`0.1.0`). Контрольные суммы, размеры и происхождение существующих бинарников нельзя менять вручную.

После полной пересборки native client provenance-скрипт обновит метаданные и хеши, а `artifactVersion` станет `0.1.0`. Для server core текущий provenance-скрипт сохраняет уже записанный `artifactVersion`, чтобы не переобозначать существующие бинарники; смена версии артефакта на `0.1.0` требует отдельного подтверждения происхождения новой сборки.
